Méthode & limites

  • Sources : hatvp.fr/open-data — liste.csv + declarations.xml (Licence Ouverte 2.0 Etalab). Aussi sur data.gouv.fr.
  • Couverture : toutes les déclarations publiées en open data (DSP/DSPM). Les DSP non publiées ne sont pas dans l'open data par design.
  • Appariement : hash interne nom+prenom+dateNaissance + même cat_mandat, tri par dateDepot. Paires entrée/sortie avec durée ≥ 0.5 an. Flag evenement_majeur (héritage/donation) isolé.
  • Anonymisation : agrégats si N≥10, 20 profils anon_* avec tranche d'âge et type de mandat uniquement. Aucune donnée nominative publiée.
  • Catégories : Immobilier (immeuble + SCI, quote-part appliquée) · Bourse · Assurance-vie · Épargne bancaire · Véhicules · Autres. Net = brut − passif.
  • Reproductible : scripts/download.py + scripts/build_data.py → 4 JSON. Relance hebdo via GitHub Actions.
