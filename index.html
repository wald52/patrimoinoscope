Méthode & limites — audit V2 24/08/2026

  • Sources : hatvp.fr/open-data — liste.csv (13330 lignes) + declarations.xml (6608 décl., 88 Mo) — Licence Ouverte 2.0. Harvest V2 : 2315 XML individuels testés via livraison/dossiers (tous déjà dans le merge, superset).
  • Couverture réelle : DSP inventaire 2633, Livrées 2344, avec XML 2343, mais téléchargeables 75 (64 DSP + 11 DSPFM). Les DSP députés/sénateurs/europe retournent 404 : Consultable en préfecture uniquement (ex: lahmar-abdelkader-dsp31970-depute-69.xml 404). Détail : audit.html et docs/DATA.md.
  • Conséquence : appariement entrée/sortie possible sur 3 paires seulement (même mandat, durée ≥0.5 an). Le site affiche donc un mock déterministe (184 paires) en attendant une ouverture légale — bascule auto si N≥10. Voir kpis.json:mode=mock,n_paires_reel=3 + onglet Réel N=3.
  • Intérêts : 6533 DI analysées pour les participations et activités — beaucoup plus robuste que le patrimoine.
  • Anonymisation : agrégats si N≥10, 20 profils anon_* avec tranche d'âge et type de mandat uniquement. Aucune donnée nominative publiée.
  • Catégories : Immobilier (immeuble + SCI, quote-part) · Bourse · Assurance-vie · Épargne bancaire · Véhicules · Autres. Net = brut − passif. Structure : opendata-structure.xlsx:257 champs.
  • Reproductible : scripts/download.py + scripts/harvest.py + scripts/build_data.py → JSON. Relance hebdo via GitHub Actions.
