Mentions légales & RGPD

Dernière mise à jour : 24/08/2026

Éditeur

Patrimoinoscope est un observatoire citoyen édité par Le Modèle Social Français (collectif citoyen).
Contact : via github.com/lemodelesocialfrancais/patrimoinoscope (Issues).

Hébergement

GitHub Pages — GitHub, Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA.
Politique de confidentialité GitHub

Sources & licence

Données : HATVP open data — liste.csv (13330 lignes) + declarations.xml (6608 décl.) — Licence Ouverte 2.0 Etalab (réutilisation libre avec mention source).
Code site : MIT.

Données personnelles & cookies

Aucun cookie déposé. Aucune donnée nominative publiée : seuls des agrégats anonymisés (anon_*) sont affichés. Les noms/prénoms/dates de naissance sont hachés côté build et jamais publiés (grep -r Baptiste data/ vide).
Mesure d'audience : Plausible Analytics sans cookie, anonyme, hébergé UE, conforme RGPD (pas de consentement requis). Vous pouvez vous opposer via Do Not Track.

Finalité

Information citoyenne sur l'évolution macro du patrimoine et des intérêts des élus. Aucun profilage nominatif, aucune décision automatisée.

Responsabilité

Malgré le soin apporté (hash, N≥10, mock signalé), des erreurs de parsing XML peuvent subsister. Signalez-les via GitHub Issues. Les 75 DSP téléchargeables ne permettent que 3 paires réelles — le site l'affiche en bandeau.

Accessibilité

Site vanilla HTML/CSS/JS, conforme RGAA 4.1 visé AA (contrastes, focus, aria, prefers-reduced-motion). Signalez un défaut d'accessibilité via Issues.
